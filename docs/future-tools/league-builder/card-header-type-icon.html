Gym card header — the 1×1 type icon

The wide type chip goes. In its place the square Gen IX type icon — the same asset the browser and the analytics pages already use — sits between the back chevron and the identity block, and the page name and the theme field both run to the right of it. Every bar below is the app's own 44px tool bar at a 393px phone width, and the icons are the real PNGs.

Today, for reference

The 4.75rem chip rides the name line. It is 76px wide, which is a fifth of the bar, and it pushes the name line to 15.2px so the theme field can sit level with the league home's own field.

What the theme costs

The square is smaller than the chip — 30px against 76px — but it stands beside the whole text stack rather than on the name line, so the theme pays for it. Measured in these bars: the theme field goes from 258px to 221px, which is 37px, or about six characters. It is the shipped chip that is free, because it rides a line the theme does not use.

The third bar is the way to keep both: the square sits beside the name line only, and the theme field starts back at the block's left edge and runs the full width. It is not what was asked for — the theme no longer begins to the right of the icon — and it costs height instead: the square has to come down to 24px, because 30px plus the editable line under it is 49.5px in a 44px bar.

The empty square

A square with a plus in it says “add something”, not “add a type”. The card already answers that on its own marks: the TM disc and the badge hexagon each carry their word underneath, in 0.5rem extrabold. The same word here makes the square say what it is for. Five ways to set it, all at 30px.

Notes

  • The icon is a control, the way the chip is: pressing it opens the type picker.
  • With the chip out of the text stack, the name line no longer has to be 15.2px tall. HEADER_HEAD_H exists only to make room for the chip, and both headers can drop it and go back to an 11px name line. The bars above are drawn that way, which is why the theme sits two pixels higher than the shipped bar beside it. The league home would move with it.
  • HEADER_FIELD_H stays. That one is not about the chip: the home's field is 14px type and the card's is 11px, so without one pinned height the two dashed underlines land at different heights again.
  • The square carries no word, so it says nothing to a screen reader on its own. Its button keeps the Gym type label, and the label names the chosen type.
  • Unlike the chip, the square does not name the type in the reader’s language. The card’s whole colour scheme already comes from the type, so the icon is a second signal rather than the only one — but a person who does not know the Gen IX symbols loses the word.
