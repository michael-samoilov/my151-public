# The admin dashboard is a query view of "/"; the demo and tuning states are
# query views of the tool pages. None has standalone value in search results,
# and each page's canonical points at its own clean URL.
#
# Two deliberate choices here, both for cross-parser correctness:
#  - Plain prefixes, not "/*?admin". These views are always entered at exactly
#    these URLs, and prefix rules are honored everywhere, whereas "*"
#    wildcards are a Google/Bing extension.
#  - Disallow listed *before* "Allow: /". Google resolves conflicts by longest
#    match, but older first-match-wins parsers would otherwise stop at
#    "Allow: /" and never reach these lines. This order is correct under both.
